# FPGA-CNN-Accelerator

This project is an FPGA based CNN accelerator for the Ecto-Trigger insect detection model. The model analyzes an input image to determine whether or not an insect is present in the image; this behavior will utilized with the intention of flagging images likely to contain insects for researcher review. The accelerator will be tailored to benefit the computations performed by the model and optimized for low power to allow for wildlife surveillance over long periods of time. This project will serve as a prototype for what could eventually be a camera trap capable of detecting insects in remote environments and flagging images for researcher review.

Ecto-Trigger Model: https://github.com/rossGardiner/ecto-trigger/
